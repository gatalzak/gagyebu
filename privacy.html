‹ 가탈작 가계부

개인정보처리방침

시행일: 2026년 10월 10일

1. 수집하는 정보

가탈작 가계부는 운영자 서버를 두지 않으며, 이용자의 개인정보를 수집하거나 운영자에게 전송하지 않습니다. 이용자가 입력한 수입·지출 내역, 자산·부채 정보는 이용자의 기기(브라우저 저장공간)에만 저장됩니다.

2. 구글 드라이브 연동

이용자가 직접 「구글 드라이브 연결」을 선택한 경우에 한해, 가계부 데이터를 이용자 본인의 구글 드라이브에 클로드가계부_동기화.json 파일로 저장해 기기 간에 동기화합니다.

  • 요청 권한은 drive.file(이 앱이 만든 파일에만 접근)이며, 드라이브의 다른 파일은 읽거나 수정하지 않습니다.
  • 자동 재연결을 위해 연결한 구글 계정의 이메일 주소를 이용자 기기에만 저장합니다.
  • 구글로부터 받은 정보는 동기화 목적 외에 사용하지 않으며, 제3자에게 제공·판매하지 않습니다.

3. 외부 서비스

  • 환율 정보: 외화 금액을 원화로 환산하기 위해 open.er-api.com에서 공개 환율을 받아옵니다. 이 요청에는 가계부 데이터나 개인정보가 포함되지 않습니다.
  • 웹 호스팅: 앱 화면 파일은 GitHub Pages에서 제공됩니다. 가계부 데이터는 GitHub에 저장되지 않습니다.

4. 보관 및 삭제

데이터는 이용자가 삭제할 때까지 이용자의 기기와 구글 드라이브에 보관됩니다. 브라우저 데이터 삭제 또는 앱 삭제로 기기의 데이터를, 구글 드라이브에서 위 파일 삭제로 드라이브의 데이터를 지울 수 있습니다. 구글 계정 설정(보안 → 서드 파티 액세스)에서 이 앱의 접근 권한을 언제든 해제할 수 있습니다.

5. 문의

문의는 GitHub 저장소를 통해 남겨 주세요.
